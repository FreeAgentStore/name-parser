# Name Parser

Parse human names into components — prefix, first, middle, last, suffix. Handles Western, Eastern, Hispanic, Arabic, and mononym formats.

Part of [FreeAgentStore](https://freeagentstore.online) — AI tools that run free in your browser.

## Install

```bash
npm install @freeagentstore/name-parser
```

## Usage

```ts
export { parseName } from "@freeagentstore/name-parser";
```

## ESM (zero install)

```html
<script type="module">
  import { ... } from 'https://freeagentstore.online/pkg/name-parser/index.js'
</script>
```
